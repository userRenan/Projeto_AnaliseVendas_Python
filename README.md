# 📊 Análise de Vendas com Python

## 📌 Sobre o projeto

Este projeto apresenta uma análise exploratória de dados de vendas utilizando Python e ferramentas de Ciência de Dados.

O objetivo é explorar os dados, identificar padrões de vendas e gerar informações que possam auxiliar na interpretação dos resultados.

## 🛠️ Tecnologias utilizadas

* Python
* Pandas,Numpy,Matplotlib,seaborn
* Jupyter Notebook
* Funções

## 📈 Análises realizadas

Durante o projeto foram realizadas análises como:

* Análise dos produtos vendidos
* Faturamento por categoria
* Identificação dos produtos com maior volume de vendas
* Análise dos dados de vendas
* Criação de visualizações para facilitar a interpretação dos resultados

## 📊 Visualizações

O projeto utiliza gráficos para apresentar os resultados das análises de forma visual e facilitar a compreensão dos dados.

## ▶️ Como executar o projeto

Para executar o projeto, é necessário ter Python instalado e um ambiente capaz de executar arquivos Jupyter Notebook.

1. Clone este repositório:

```bash
git clone https://github.com/userRenan/Projeto_AnaliseVendas_Python.git
```

2. Acesse a pasta do projeto:

```bash
cd Projeto_AnaliseVendas_Python
```

3. Abra o arquivo `ProjetoVendas.ipynb` no Jupyter Notebook ou JupyterLab.
